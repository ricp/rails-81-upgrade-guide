📋 Overview

Action Push Native brings first-class push notification support to Rails with direct integration with Apple Push Notification Service (APNs) and Firebase Cloud Messaging (FCM).

Key Benefits

  • 💰 Zero Third-Party Fees - Direct APNs/FCM integration eliminates subscription costs
  • 📊 Production Proven - Zero Third-Party Fees
  • 🔒 Full Control - Own your notification infrastructure
  • ⚡ High Performance - Optimized delivery with built-in retry logic

See the full technical documentation for complete implementation details, platform-specific setup, device management, rich notifications, and integration examples.
